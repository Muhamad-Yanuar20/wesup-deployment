# Product Requirements (PRD)

Product requirements live in `prd/` as Markdown files (e.g. `prd/feature-name.md`). This folder is git-ignored — PRDs are private working documents and must never be committed. When implementing a feature, consult the PRD first and align code and decisions with it.
